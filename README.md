# java-racingcar-precourse

## 요구사항 정리 📑

1. 입력 1 : 경주할 자동차 이름을 입력한다.

   ☑️ `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`

2. 입력 2 : 시도할 이동의 횟수를 입력한다.

   ☑️ `시도할 횟수는 몇 회인가요?`

3. 출력 : 결과를 출력하기 시작한다.

   ☑️ `실행 결과`

4. 각 자동차마다 무작위 랜덤 값을 구한다. 이때 해당 값이 4 이상인 경우, 전진의 의미로 ‘-’ 를 출력하고 해당 값이 3 이하인 경우, 어떠한 출력도 하지 않는다.

   ✔️ 이때 정렬 순서는 사용자가 입력한 자동차 순서와 같다.

   ✔️ 전체 자동차의 실행이 끝나면 다음 세트로 이어지기 전 줄바꿈을 해준다.

   ✔️ 사용자가 입력한 시도 횟수만큼 해당 과정은 반복된다.

5. 자동차 중 가장 전진 (‘-’) 횟수가 많은 자동차를 구한다.
6. 출력 : 최종 우승자를 출력한다. 이때, 우승자는 한 명 이상일 수 있다.

   ☑️ `최종 우승자 : `


- 들여쓰기 depth는 2까지만 허용된다.
- 삼항 연산자를 쓰지 않는다.
- 기능 목록에 대한 테스트 코드를 작성한다.
- 사용자가 잘못된 값을 입력할 경우,`IllegalArgumentException`을 발생시킨다.
- `camp.nextstep.edu.missionutils`에서 제공하는`Randoms`및`Console`API를 사용하여 구현한다.

  ✅ Random 값 추출 : `pickNumberInRange()`

  ✅ 사용자 입력 : `readLine()`

## 구현할 기능 목록 ⚙️

## 문자열 입출력 기능 💡
### ✔️ InputView

1. 자동차 이름을 입력받는다.
2. 시도할 이동의 횟수를 입력받는다.

<br />

### ✔️ OutputView

1. 라운드 별 실행 결과를 출력한다.
2. 최종 우승자 안내 문구를 출력한다.

<br />

## 레이스 기능 💡
### ✔️ ReadyController

1. 입력 → 레이스 환경 세팅의 제어 흐름을 구성한다.
2. 전달용 객체인 `RaceConfig`의 생성을 담당한다.

<br />

### ✔️ RacingController

1. 시도 횟수에 따른 게임 진행 → 결과 반환의 제어 흐름을 구성한다.
2. `ReadyController`로부터 생성된 `RaceConfig`의 데이터를 이용한다.

<br />

### ✔️ PreparationHelper

1. 자동차 이름을 쉼표(,)를 기준으로 구분한다.
    1. 입력된 자동차 개수가 1개 이하인 경우, 예외 처리한다.
2. 시도할 이동 횟수를 검증한다.
    1. 횟수가 숫자 타입이 아닌 경우, 예외 처리한다.
    2. 횟수가 양수가 아닌 경우(0또는 음수), 예외 처리한다.
    3. 숫자(int 타입)값의 오버플로우를 체크한다.

<br />

### ✔️ RandomNumberHelper

- 0에서 9 사이의 무작위 값을 생성한다.

<br />

### ✔️ Cars

1. Car의 리스트를 담당하는 일급 컬렉션이다.
2. 중복된 자동차 이름이 있는 경우, 예외 처리한다.
3. 자동차들이 전진한 횟수 중 가장 큰 전진 횟수 및 우승자를 저장한다.

<br />

### ✔️ Car

1. 자동차를 생성한다.
    1. 이름 중 빈 문자열이 있는 경우, 예외 처리한다.
    2. 자동차 이름이 6자 이상인 경우, 예외 처리한다.

<br />

### ✔️ Race

1. 자동차마다 무작위 번호를 돌려 전진 유무를 결정한다.
2. 우승자를 판단한다.

<br />

## 기타 💡
### ✔️ RacingConfig

- 단순 상태 전달의 목적만 가지고 있는 전달용 객체
- `ReadyController`에서 생성되고, `RacingController`에서 사용된다.

<br />

### ✔️ ErrorMessages

- 예외 메시지 전용 상수 클래스

<br />
<br />

## 예외 처리 ⚠️

1. 총 경주에 참여하는 자동차의 개수가 1개 이하인 경우
2. 중복된 자동차 이름이 존재하는 경우
3. 이름 중 빈 문자열이 있는 경우
4. 자동차 이름이 6자 이상인 경우
5. 사용자가 입력한 시도 횟수가 숫자가 아닌 경우
6. 사용자가 입력한 시도 횟수가 양수가 아닌 경우 (음수 또는 0)
